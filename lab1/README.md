# lab1

Алфавит: `{a,b}`. Исходная система переписываний `T`:
```
(1) aaa -> bab
(2) bbb -> aaa
```

---

## 1) Завершимость

Разобьём слово `w` на максимальные подряд идущие блоки `a` (a-блоки). Для блока длины `n` положим
```
blk(n) = ceil(n / 3)
```
и определим потенциал
```
B(w) = сумма blk(n) по всем a-блокам в w.
```
Очевидно, `0 <= B(w) <= |w|`, так как `ceil(n/3) <= n`, а сумма длин всех a-блоков не превосходит `|w|`.

### Лемма 1
Для шага `(1) aaa -> bab` выполняется `ΔB >= 0`.

Доказательство. Пусть редекс внутри блока `a^{p} aaa a^{q}`. Вклад был `ceil((p+3+q)/3)`, стал
```
ceil(p/3) + ceil(1/3) + ceil(q/3) = ceil(p/3) + 1 + ceil(q/3).
```
Разность
```
ΔB = ceil(p/3) + ceil(q/3) - ceil((p+q)/3) ∈ {0,1},
```
значит `ΔB >= 0`.

### Лемма 2
Для шага `(2) bbb -> aaa` выполняется `ΔB >= 0`, а если редекс у границы слова или рядом с `b` (т.е. слева или справа нет `a`), то `ΔB = 1`.

Доказательство. Пусть окружение `a^{p} bbb a^{q}`. Было `ceil(p/3)+ceil(q/3)`, стало один блок длины `p+3+q` с вкладом
```
ceil((p+3+q)/3) = 1 + ceil((p+q)/3).
```
Отсюда
```
ΔB = 1 + ceil((p+q)/3) - ceil(p/3) - ceil(q/3) >= 0.
```
Если `p=0` или `q=0`, то прямо видно `ΔB = 1`.

Следствие: на любом шаге `B` не убывает; на шаге `(2)` у границы - строго растёт.

### Циклов нет - терминальность
Так как длина сохраняется, для фиксированного `n` множество слов конечно. Бесконечная цепочка длины `n` содержит цикл `w =>+ w`. В цикле сумма `ΔB` равна 0, значит каждый шаг имеет `ΔB = 0` (иначе `B` вырос бы).

Возьмём цикл минимальной длины слова `|w|`. В нём есть шаг, начинающийся в позиции 1: иначе первый символ фиксирован, а суффикс длины `|w|-1` дал бы меньший цикл.

Если в позиции 1 применено `(2)`, то слева граница и по лемме 2 `ΔB=1`, что на цикле невозможно. Если применено `(1)`, первый символ становится `b`, а чтобы вернуть его в `a`, позже нужно применить `(2)` в той же позиции - снова `ΔB=1`. Противоречие. Значит циклов нет, бесконечных цепочек тоже, система `T` завершается.

## 2) Конечность классов эквивалентности по НФ

Рассматриваем систему как тождества
```
aaa ≈ bab 
bbb ≈ aaa
```
то есть допускаем шаги в обе стороны. Тогда редексами являются ровно три трёхграммы {aaa, bab, bbb}.

Тогда каждое слово вида `(aab)^n` (для любого `n >= 0`) не содержит редексов, т.е. каждое `(aab)^n` - нормальная форма. Множество `{(aab)^n | n >= 0}` бесконечно.

Заметим, что длина слова сохраняется при любом шаге переписывания. У `(aab)^n` длина 3n, поэтому эти НФ попарно неэквивалентны при разных n. Следовательно, и классов эквивалентности бесконечно много.

## 3) Локальная конфлюэнтность

Локальная конфлюэнтность нарушается. Критическая пара от перекрытия `aaa` с `aaa` (сдвиг на 1):
```
aaaa -> baba
aaaa -> abab
```
Оба результата не содержат `aaa`/`bbb`, т.е. это разные нормальные формы. Следовательно, `T` не локально конфлюэнтна (и, так как `T` терминальна, - не конфлюэнтна).

## 4) Пополняемость (Кнут–Бендикс)

Берём shortlex (`a < b`) и переориентируем, получая `T'`:
```
(1') bab -> aaa
(2') bbb -> aaa
```
Эта система терминальна под shortlex. Проверим пополняемость. На критических парах возникает серия новых правил:

Для чётного `n >= 2`, пусть `w_n = b (ab)^n`. Тогда
  ```
  b (ab)^n ->* a^(2n) b
  b (ab)^n ->* b a^(2n)
  ```
  Получаем равенство `b a^(2n) ≈ a^(2n) b`, которое shortlex ориентирует как
  ```
  b a^(2n) -> a^(2n) b   (для каждого четного n >= 2)
  ```

Аналогично из перекрытий `bbb` с `bbb` появляется серия
  ```
  bb a^(2m+3) -> a^(2m+3) bb   (m >= 0)
  ```

Поскольку эти серии бесконечны, алгоритм Кнута–Бендикса не завершается: `T'` не пополнима.
