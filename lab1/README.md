# lab1

Алфавит: `{a,b}`. Исходная система переписываний `T`:
```
(1) aaa -> bab
(2) bbb -> aaa
```

---

## 1) Завершимость

Рассмотрим
```
F(w) = #aa(w) + #bb(w)   (число равных соседних пар)
```
Для шага `(1) aaa -> bab`: внутри редекса исчезают две пары `aa`, внутри `bab` равных пар нет. На границах может появиться не более одной `bb` с каждой стороны, поэтому `ΔF <= -2 + 1 + 1 <= 0`. Равенство возможно только в окружении `b [aaa] b`.

Для шага `(2) bbb -> aaa`: внутри редекса количество пар не меняется (`2 -> 2`), меняются только границы; `ΔF ∈ {-2, 0, +2}` и рост `+2` возможен только в окружении `a [bbb] a`.

Если случился «плохой» шаг с `ΔF = +2` (контекст `a [bbb] a`), тут же доступен шаг `(1)` на том же месте, который даёт `ΔF <= -4`. Значит всякая пара шагов «(2) затем (1)» уменьшает `F` минимум на 2, а все прочие шаги `F` не увеличивают. Так как `0 <= F(w) <= |w|-1`, бесконечной цепочки нет - `T` завершается.

---

## 2) Конечность классов эквивалентности по НФ

Рассматриваем систему как тождества
```
aaa ≈ bab 
bbb ≈ aaa
```
то есть допускаем шаги в обе стороны. Тогда редексами являются ровно три трёхграммы {aaa, bab, bbb}.

Тогда каждое слово вида `(aab)^n` (для любого `n >= 0`) не содержит редексов, т.е. каждое `(aab)^n` - нормальная форма. Множество `{(aab)^n | n >= 0}` бесконечно.

Заметим, что длина слова сохраняется при любом шаге переписывания. У `(aab)^n` длина 3n, поэтому эти НФ попарно неэквивалентны при разных n. Следовательно, и классов эквивалентности бесконечно много.

---

## 3) Локальная конфлюэнтность

Локальная конфлюэнтность нарушается. Критическая пара от перекрытия `aaa` с `aaa` (сдвиг на 1):
```
aaaa -> baba
aaaa -> abab
```
Оба результата не содержат `aaa`/`bbb`, т.е. это разные нормальные формы. Следовательно, `T` не локально конфлюэнтна (и, так как `T` терминальна, - не конфлюэнтна).

---

## 4) Пополняемость (Кнут–Бендикс)

Берём shortlex (`a < b`) и переориентируем, получая `T'`:
```
(1') bab -> aaa
(2') bbb -> aaa
```
Эта система терминальна под shortlex. Проверим пополняемость. На критических парах возникает серия новых правил:

Для чётного `n >= 2`, пусть `w_n = b (ab)^n`. Тогда
  ```
  b (ab)^n ->* a^(2n) b
  b (ab)^n ->* b a^(2n)
  ```
  Получаем равенство `b a^(2n) ≈ a^(2n) b`, которое shortlex ориентирует как
  ```
  b a^(2n) -> a^(2n) b   (для каждого четного n >= 2)
  ```

Аналогично из перекрытий `bbb` с `bbb` появляется серия
  ```
  bb a^(2m+3) -> a^(2m+3) bb   (m >= 0)
  ```

Поскольку эти серии бесконечны, алгоритм Кнута–Бендикса не завершается: `T'` не пополнима.
